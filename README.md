# 붕어빵 타이쿤 · 작은 노점

붕어빵타이쿤3의 튜토리얼을 바탕으로 새로 작성한 비공식 터치 재구성입니다. 원작 © 컴투스. v2는 사용자가 승인한 화풍의 ImageGen 생성 전신 손님 10종, 단계별 가게 배경 10종, 굽기 이미지 8종과 소품 4종을 사용합니다. 원작 게임 코드를 그대로 실행하는 에뮬레이터는 아닙니다. 폰트 Jua는 SIL OFL (assets/OFL.txt).

## 아이폰
Safari에서 공개 주소를 열고 공유 → 홈 화면에 추가. 처음 실행해 오프라인 준비 완료 표시를 확인한 후 인터넷 없이 사용할 수 있습니다. 실제 아이폰 하드웨어 검증은 별도입니다.

## 플레이
빈 틀 → 뒤집기 표시 → 꺼내기 표시 순서로 탭. 구운 빵이 주문 수 이상이면 손님을 탭해 판매. 덤 +1은 한 개 더 소비하고 콤보 보너스를 줍니다. 펌프로 4초간 굽는 속도를 올립니다. 황금 표시가 뜬 순간 수확하면 50원 보너스. 2분 장사 후 다음 날로 이어집니다. 리어카 → 지붕 리어카 → 포장마차 → 동네 노점 → 작은 가게 → 골목 맛집 → 붕어빵 전문점 → 동네 명물 → 프리미엄 매장 → 붕어빵 궁전의 10단계 외관/가격 성장이 있습니다. 장비 3종은 별도로 각 3단계입니다. 무료 반죽이라 돈이 없어도 계속 플레이할 수 있습니다.

## 범위
손님은 원작에서 영감을 받은 새 전신 일러스트입니다. 동시에 같은 외형이 중복 등장하지 않습니다.

원작 코드 전체 포팅이 아닙니다. 터치 조작, 2분 영업, 가격·시간·업그레이드 수치는 새 설계입니다. 원작의 펫 진화·온라인 길드·랭킹·모든 게임 모드는 포함하지 않습니다. 원본 MMF 음원 대신 선택 가능한 합성 효과음을 사용합니다.

## 저장
기기와 사이트 주소별 localStorage에 자동 저장. 메뉴의 JSON 백업/복원 지원. 앱 전환 시 일시정지, 오프라인 경과시간 없음. Safari 데이터 삭제 전에 백업하세요. 서버로 저장 정보를 보내지 않습니다.
